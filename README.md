# LockIn

**[Download the latest release](https://github.com/cchow375/LockIn-Releases/releases/latest)**

Your planner, assignments, notes, and study plans on Mac and Windows. No Xcode or GitHub account needed.

## Mac

1. Download the ZIP without Windows in its name.
2. Unzip it and quit your old LockIn.
3. Drag LockIn.app into Applications. Replace the old copy.
4. Open it from Applications and sign in.

If macOS blocks this private beta, try opening it once, then choose System Settings → Privacy & Security → Open Anyway. Only approve the copy from this release page. Requires macOS 13 or newer, Intel or Apple silicon.

## Windows 11

1. Download the ZIP with Windows in its name.
2. Right-click → Extract All. Keep the extracted files together.
3. Open LockIn.exe. Sign in with the same account as your Mac.

This is an unsigned portable Windows x64 app; your device may require approval to open it.

## Updates

Mac: install this first release once. LockIn checks automatically while open and online. You can also choose LockIn → Check for Updates. Follow the installation and relaunch prompt.

Windows: LockIn checks for signed releases and offers a verified ZIP download. Quit the app, extract the new ZIP into a new folder, and open its LockIn.exe. Manual replacement is currently required on Windows.

Your account data stays. Bookmark this page; you do not need a new link for each version.

## Sync

Use the same email and password on your own computers. Friends should create their own accounts. Keep both apps open and online; changes normally arrive within seconds.

- Synced: the server acknowledged this computer’s planner.
- Syncing: changes are being exchanged.
- Offline or Not synced: read the inline issue; local planner edits are kept and retried.

Wait for Synced before switching computers. Offline or sleeping computers catch up when they reconnect.

## Windows coverage

Windows supports the shared planner, assignments, blocks, classes, links, timetable, notebook, day notes, study plans, and a local focus timer. Imported calendar and assignment data synced from Mac appears on Windows.

Direct Canvas/Google setup, native assistant chat, paired focus sessions, and rich-text authoring remain Mac features. Editing a rich-text note in Windows converts that note to plain text; the app explains this first. The original Mac app remains available.
