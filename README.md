# LockIn

Your planner, notes, assignments, and study plans — on Mac and Windows.

**[Download the latest release](https://github.com/cchow375/LockIn-Releases/releases/latest)**

This repository contains app downloads and update files. You do not need the source code, Xcode, or a GitHub account to use LockIn.

## Install on a Mac

1. Open the download link above. Under **Assets**, download the `LockIn-VERSION-BUILD.zip` file whose name does **not** include Windows.
2. Unzip it. Quit your old LockIn if it is open.
3. Drag **LockIn.app** into **Applications**. Replace the old copy if asked.
4. Open it from Applications. Sign in, or create your own account.

This private beta is not Apple-notarized. If macOS blocks it, first try opening the app, then select **System Settings → Privacy & Security → Open Anyway**. Only approve a copy from this release page. School-managed Macs may require administrator approval. [Apple’s first-open instructions](https://support.apple.com/guide/mac-help/mh40616/mac).

Requires macOS 13 or newer; supports Intel and Apple silicon.

## Install on Windows 11

1. Download the asset whose name contains **Windows** and ends in **.zip**.
2. Right-click it → **Extract All**. Keep all extracted files together.
3. Open **LockIn.exe** inside the extracted folder.
4. Sign in using the same LockIn account as your Mac.

This is a portable Windows x64 app. Windows or your school’s device policy may require approval to run an unsigned application.

## Get future updates

**Mac:** install the first release from this page once. After that, LockIn checks for updates automatically while open and online. You can also choose **LockIn → Check for Updates**. Follow the installation/relaunch prompt. You keep your account and planner data.

**Windows:** the app checks for signed releases and offers a verified download. Quit LockIn, extract the new ZIP into a new folder, then run its LockIn.exe. The Windows version currently needs this manual replacement step; it does not install over a running app.

You do not need a new link from Christian for each version. Bookmark this page.

## Use two computers

Use the **same email and password** on your own computers. Friends should create their own accounts. Leave both copies open and online; changes normally arrive within seconds.

- **Synced:** this computer’s planner has been acknowledged by the server.
- **Syncing:** changes are being exchanged.
- **Offline / Not synced:** read the inline issue; local planner edits are kept and retried.

An offline, sleeping, or closed computer catches up when it reconnects. Before switching computers, wait for **Synced**. Nothing can deliver an edit instantly to an offline computer.

## What is included

Mac and Windows include the shared planner, calendar, assignments, rich notes, school timetable, friends, customizable avatars, close-up classroom scenes, shared focus sessions, floating timers, and Follow Day. Windows also includes direct Google Calendar/Canvas connections, offline timetable-photo recognition, reviewed day planning, and Google Calendar publishing.

Mac uses original 3D avatars; Windows uses lightweight CSS characters. The native AI assistant remains Mac-only. Windows is tested with automated logic/browser checks and package audits; real Windows 11 hardware validation remains outstanding.

## Beta limits

- Google connection remains limited to approved test accounts while Google's production OAuth setup is completed. Ordinary LockIn email sign-in and planner sharing do not require Google.
- Mac downloads are Sparkle-signed private-beta builds, not Apple-notarized releases. Windows downloads are portable unsigned x64 builds with signed update metadata.
- Supported downloads are macOS 13+ (Intel and Apple silicon) and Windows 11 x64. There are no iPhone, Android, Linux, or Chromebook builds.
