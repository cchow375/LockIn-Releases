## Install LockIn

### Mac

1. Click **Download for Mac** above and open the downloaded ZIP.
2. Quit any running LockIn. Move **LockIn.app** into your **Applications** folder and replace the old copy if prompted.
3. Open LockIn from Applications and sign in with your existing LockIn email and password.

The Mac beta is not Apple-notarized. If macOS blocks the first open, try opening it once, then go to **System Settings → Privacy & Security → Open Anyway**. Only approve the copy you downloaded here. A managed school computer may need administrator approval. [Apple's instructions](https://support.apple.com/guide/mac-help/mh40616/mac).

### Windows

1. Click **Download for Windows** above.
2. Right-click the downloaded ZIP → **Extract All**. Keep every extracted file together.
3. Open **LockIn.exe** in the extracted folder. Sign in with your existing LockIn email and password.

The Windows app is portable. If Windows or school policy blocks it, follow your computer administrator's approved installation process.

## Use another computer

Sign in with the **same LockIn account** on each of your own computers. Wait for **Synced** on the first computer before switching; the other copy catches up when it is open and online.

Your planner syncs through your account. Google Calendar and Canvas connections may need to be connected again on the new computer. Friends should use their own accounts.

## Get future updates

**Bookmark [this page](https://github.com/cchow375/LockIn-Releases#download-lockin).** Each link points to the latest published build for that platform. Mac updates may arrive before the next Windows build.

- **Mac:** choose **LockIn → Check for Updates**, or use the app's automatic update prompt. Finish the installation/relaunch prompt.
- **Windows:** use the verified download offered in LockIn. Quit the app, extract the new ZIP into a new folder, then open its **LockIn.exe**.
