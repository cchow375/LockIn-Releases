# Download and use LockIn

**[Open the download page](https://github.com/cchow375/LockIn-Releases#download-lockin)**, then click **Download for Mac** or **Download for Windows** at the top.

You can download the app without a GitHub account. You only need your LockIn account to sign into the app.

## Move to another computer

1. On your current computer, open LockIn and wait for its status to say **Synced**.
2. On the new computer, open the download page and click the link for that computer.
3. On **Mac**, open the ZIP and move **LockIn.app** to **Applications**. On **Windows**, right-click the ZIP → **Extract All**, then open **LockIn.exe**. Keep all Windows files together.
4. Sign in using the **same email and password** as your current LockIn account.
5. Keep the new copy open and online while it syncs. Connect Google Calendar or Canvas on that computer if needed.

If your first computer is offline or says **Not synced**, its latest local changes may not have reached the other computer yet. Reconnect and read the status message before switching.

## Where do I click on GitHub?

- **To install the app:** use the big Mac or Windows download links on the download page.
- **To see changes:** click **What's new** on that page.
- **If you are on a release page:** expand **Assets** to see downloads. Choose the Mac ZIP or the ZIP containing **Windows**.
- **If you opened a file list:** scroll down to the README, or click **README.md**.
- **If you want to build/edit the code:** use the private source repository and its developer guide. You need your existing GitHub access for that repository.

The green **Code** button and **Download ZIP** download source/repository files. They are useful for development; use the big platform download links when installing LockIn.

## If the first open is blocked

**Mac:** this beta is not Apple-notarized. Try opening LockIn once, then use **System Settings → Privacy & Security → Open Anyway** for the app downloaded from the official page. [Apple's instructions](https://support.apple.com/guide/mac-help/mh40616/mac).

**Windows:** extract the whole ZIP before opening LockIn.exe. If Windows or school policy blocks it, follow the administrator's approved installation process.

**Wrong email/password:** use LockIn's password recovery. Creating another account will create a separate planner.

**Google will not connect:** the current Google setup only accepts approved test accounts. LockIn email sign-in and planner sync do not require Google.

## Update later

On Mac, use **LockIn → Check for Updates** and finish its install/relaunch prompt. On Windows, quit LockIn, extract the newly downloaded ZIP into a new folder, and open that copy's **LockIn.exe**. Keep all neighboring files.
